# 🎵 Spotify Connect (Soloist) для Яндекс Станции Мини 2

Автономный, оптимизированный пакет **Spotify Connect** на базе официального движка **Spotify Soloist** для умных колонок **Яндекс Станция Мини 2** (а также других колонок на ARMv7 / Cortex-A35 / Allwinner / Amlogic).

---

## 🌟 Особенности этой сборки

1. **Без тяжёлого демона PulseAudio (Zero-Bloat)**:
   - Стандартный сервер PulseAudio требует 40–60 МБ оперативной памяти и падает с OOM на устройствах со 128–256 МБ RAM.
   - В комплект входит кастомная прослойка **`libpulse.so.0`**, которая перехватывает аудиопоток от Soloist и направляет его напрямую в ALSA через оптимизированный буферизованный пайп (`aplay`).
   - Потребление памяти: **всего ~18–25 МБ RAM**!

2. **Максимальное качество звука (320 kbps)**:
   - Принудительно активирован битрейт **Extreme (320 kbps Ogg Vorbis)**.
   - Включён алгоритм антиклиппинга (Headroom `-1.0 dB` и IEEE честное округление сэмплов `lrintf`), исключающий интерсемпловые искажения и хрипы на пиках.

3. **Аппаратный тюнинг усилителя Silergy SY6045S**:
   - Отключён агрессивный голосовой эквалайзер (`SPK EQ` off): убран ядовитый подъём +8 дБ на частотах 2.5–4 кГц, из-за которого звук казался шипящим.
   - Отключён компрессор речи (`SPK DRC` off): музыка звучит динамично и открыто, без сплющивания громкости.
   - Включён аппаратный даунмикс (`TDMOUT_B Lane0 Mixer`): левый и правый каналы стерео суммируются в единственный динамик колонки без потери инструментов.

4. **Полная автономность (Safe & Clean)**:
   - Не изменяет системный раздел прошивки (rootfs остаётся read-only).
   - Устанавливается целиком в раздел `/data/spotify`.
   - Включает собственный совместимый загрузчик **glibc 2.30+** (не требует обновления системных библиотек прошивки).

---

## 📋 Требования

1. **Яндекс Станция Мини 2** с доступом по **ADB** (по Wi-Fi на порт 5555 или по USB) либо **SSH**.
2. Аккаунт **Spotify Premium**.
3. Бесплатный **Soloist API Key** (`spak_...`):
   - Зайдите на [Spotify Developer Dashboard (Soloist)](https://developer.spotify.com/dashboard/soloist).
   - Нажмите **Create an App** (выберите тип устройства *Speaker* или *Audio Device*).
   - Скопируйте сгенерированный ключ доступа вида `spak_...`.

## 🚀 Быстрая установка

### Вариант 0. В будущем Через YAM (Y Application Manager)
Если на вашей Станции установлен [YAM (`nyakokitsu/yam`)](https://github.com/nyakokitsu/yam):
```bash
# Установка готового пакета .yap
yam install spotify-soloist.yap

# Включение автозапуска как сервис
yam enable spotify-soloist

# Логи в реальном времени
yam logs spotify-soloist
```

---

### Вариант 1. Через ADB (рекомендуется без YAM)
Подключитесь к колонке через ADB:
```bash
adb connect 192.168.1.XX:5555   # IP вашей колонки
```
Запустите скрипт установки из папки `mini2-spotify`:
```bash
chmod +x install.sh
./install.sh adb
```
Скрипт спросит ваш **Spotify API Key** и желаемое **имя колонки** (например, `Яндекс Мини 2`), скопирует все файлы на станцию и запустит воспроизведение.

---

### Вариант 2. Через SSH
Если на колонке настроен SSH-сервер:
```bash
./install.sh root@192.168.1.XX
```

## 🎛️ Управление сервисом

На самой колонке управление осуществляется через скрипт `/data/spotify/service.sh`:

```bash
# Статус работы и текущий играющий трек
/data/spotify/service.sh status

# Управление воспроизведением
/data/spotify/service.sh ctl play      # Возобновить
/data/spotify/service.sh ctl pause     # Пауза
/data/spotify/service.sh ctl next      # Следующий трек
/data/spotify/service.sh ctl prev      # Предыдущий трек
/data/spotify/service.sh ctl volume 30 # Установить громкость 30%

# Просмотр логов в реальном времени
/data/spotify/service.sh log

# Перезапуск / остановка
/data/spotify/service.sh restart
/data/spotify/service.sh stop
```

---

## 🔄 Автозапуск при включении колонки

Чтобы Spotify запускался автоматически при перезагрузке колонки, добавьте вызов сервиса в конец скрипта автозапуска (обычно `/data/run.sh` или `/data/auto_run.sh`):

```bash
echo "/data/spotify/service.sh start" >> /data/run.sh
chmod +x /data/run.sh
```

## 📁 Структура пакета

```
mini2-spotify/
├── bin/
│   └── soloist             # 32-битный бинарник Spotify Soloist (ARMv7)
├── glibc/                  # Изолированный загрузчик glibc 2.30+ (ld-linux-armhf.so.3)
├── lib/
│   └── libpulse.so.0       # Оптимизированный аудио-шим PulseAudio -> ALSA
├── src/
│   ├── libpulse.c          # Исходный код аудио-прослойки
│   └── build_shim.sh       # Скрипт сборки libpulse под ARMv7
├── install.sh              # Инсталлятор для ADB / SSH
├── service.sh              # Демон-менеджер и CLI управления
└── README.md               # Это руководство
```

## 🛠️ Сборка шима из исходников (для разработчиков)

Если вы хотите изменить логику обработки звука или собрать библиотеку под другую архитектуру:

1. Установите кросс-компилятор:
   ```bash
   sudo apt-get install gcc-arm-linux-gnueabihf
   ```
2. Запустите сборку:
   ```bash
   cd src
   ./build_shim.sh
   ```
   Собранная библиотека автоматически обновится в `lib/libpulse.so.0`.

## 💡 Важный совет по акустике

Корпус Яндекс Станции Мини 2 спроектирован с фазоинвертором и низкочастотными каналами, направленными вниз в основание.
- **Ставьте колонку на плотную, массивную поверхность** (деревянный стол, каменная столешница, полка без зазоров).
- Если колонка висит в воздухе, стоит на решётке или на тонкой подвесной доске с пустотой под ней, возникает фазовое самопогашение баса и дребезг («подпёрживание»). Установка на плотную плоскость сразу возвращает глубокий чистый бас.
